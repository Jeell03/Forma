# Forma — Creative Learning Landing Page

A modern **student UI/UX design concept** for Forma, a fictional online design school offering practical, project-based learning. Created in Figma for an individual UI/UX assignment.

## Features
- Landing-page design for a fictional online design school
- Header with logo, navigation links, and call-to-action button
- Hero section introducing Forma and its learning experience
- Three feature cards highlighting the platform's benefits
- Course preview cards showcasing learning opportunities
- Student work section displaying creative projects
- Testimonial section with sample student feedback
- Closing call-to-action section and footer
- Auto Layout for sections, navigation, cards, and buttons
- Three reusable components: Primary Button, Feature Card, and Course Card
- Shared color and typography styles for consistent visual design

## Files
- `README.md` — project overview and documentation

## Design system

Warm ivory backgrounds, cobalt blue accents, expressive serif headings, and clean, readable body typography. Generous spacing and a clear visual hierarchy create an approachable, creative-school identity.

## Figma deliverables

Designed in Figma using Auto Layout, reusable components, and shared color and typography styles. The landing page includes a header, hero, feature cards, course previews, student work, testimonial, closing CTA, and footer.

**Target audience:** Early-career designers and career changers seeking practical, project-based learning.

**Design choices:** Warm ivory backgrounds create a welcoming atmosphere, expressive serif headings add personality, and cobalt accents highlight important actions. Clear hierarchy and generous spacing make the content easy to scan.

**Figma link:** [View Forma in Figma](https://www.figma.com/design/oEuQraxLjmaoUn6CLrVAu5/Forma?node-id=0-1)

## Scope and honesty

Forma is a fictional online design school created for academic UI/UX coursework. This project represents **only the landing-page design created in Figma**. Course previews and testimonials are illustrative content, not verified real offerings or student reviews. It does not include a functional learning platform, backend, or enrollment system.
